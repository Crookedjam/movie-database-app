# movie-database-app
Built a C# database application using SQL Server and Visual Studio. The application allows users to search and filter movie records while demonstrating skills in database design, SQL queries, data binding, and object-oriented programming.
What I Learned
Connecting a C# application to a SQL Server database
Writing SQL queries to retrieve and filter data
Creating user interfaces using Windows Forms
Working with datasets, table adapters, and data binding
Debugging database and application issues
